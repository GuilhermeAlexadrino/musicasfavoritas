# Minhas músicas favoritas

Página web simples, feita em HTML, para guardar as minhas músicas favoritas dos cantores Bryson Tiller e Olivia Dean. Atividade do curso técnico de Desenvolvimento de Sistemas (Etec, modalidade online).

## O que a página tem

- Título da aba do navegador: "Minhas músicas favoritas"
- Título do corpo da página: "Minhas músicas favoritas: Guilherme Alexandrino Menezes de Paula"
- 5 músicas, cada uma com:
  - o nome da música e do cantor, acima da imagem (tag `<h1>`)
  - uma imagem (tag `<img>`)
  - um link para ouvir a música no YouTube, abaixo da imagem (tag `<a>`)

## Como abrir

1. Baixe ou clone este repositório.
2. Mantenha o arquivo `index.html` e a pasta `imagens` juntos, na mesma pasta.
3. Dê dois cliques no `index.html` para abrir no navegador.

Não é preciso instalar nada.

## Tecnologias

- HTML5

## Observações

- As imagens são usadas localmente, por isso a pasta `imagens` precisa ficar ao lado do `index.html`.
- O código está comentado para facilitar o estudo.
- Os links levam à busca da música no YouTube.
